手动注入事件

手动按钮会停止自动演示，但不会停止时钟：错误屏仍按 4 s、情绪按 2.5 s、wake 按 1.2 s 自动超时。 想冻结画面时按“冻结时钟”，或用“时间 +1s”逐格推进超时。

设备 / PTT
语音状态
WiFi
断开会把 DEVICE 置为 LOW_BATTERY、VOICE 置为 DISCONNECTED；STA 重连成功会切回 READY。
电池
READY 会清除低电并回到 IDLE；之后 10% 的 BATTERY 事件会重新断言低电。
情绪
非 NEUTRAL 情绪持续 2.5 s，之后回到 IDLE（睡眠或离线时被更高优先级覆盖）。
错误
错误屏持续 4 s；AUDIO 复用 TTS 屏，AUTH / GENERIC 复用 LLM 屏，NETWORK 映射到 OFFLINE。
字幕 / 状态 / Toast
STATUS 覆盖 5 s（状态机仍继续切屏）；SUBTITLE 由状态机保存；TOAST 覆盖 2 s。

50
仅 LISTENING 屏显示 9 根波纹；高度公式与 panda_ui_set_audio_level() 一致，最高 72 px。
可核对项：屏幕优先级 sleep > low_battery > error > wake > offline > voice > emotion > idle； 超时 wake 1.2s / emotion 2.5s / error 4s / connecting 20s / listening 15s / thinking 20s / cancelling 0.4s。 自动演示在事件之间插入 220 ms 节拍，用于让每一屏可见；不为展示而添加状态机里没有的规则。
